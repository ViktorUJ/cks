# Аудит переводов ICA — главы, лабораторные и решения

Проверен архив **`ica(1).zip`**. Русские версии используются как источник смысла.

## Объём проверки

- **32 главы курса** (`course/01` … `course/32`) × RU/EN/ES/FR/DE/GE/JP/TW.
- **35 лабораторных** (`labs/01` … `labs/35`) × 8 языков.
- **35 эталонных решений** × 8 языков.
- Корневые README и `course/README*`.
- Смысл перевода: пропуски, отрицания, порядок действий, ограничения, числа, технические условия.
- Технические литералы, команды, YAML/JSON/API-поля, Istio/Kubernetes-объекты.
- Markdown, таблицы, Mermaid и code blocks.
- Языковые переключатели.
- Ссылки **course → lab** с проверкой языка target-файла.
- Ссылки в lab/solution README и существование их локализованных target-файлов.

## Что прошло проверку

- Во всех 32 главах присутствуют все 8 языковых файлов.
- Во всех 35 лабораторных присутствуют все 8 локализованных README.
- Во всех 35 лабораторных присутствуют все 8 локализованных solutions.
- Навигация между языками в главах, lab README и solutions ведёт на существующие файлы нужного языка.
- `course/README*` содержит 32 ссылки на локализованные главы; язык target совпадает с языком README.
- Проверено **40 ссылок course → lab на каждый язык (320 всего)**: неправильного языка и отсутствующих target-файлов не найдено.
- Набор лабораторий, на которые ссылается каждый перевод главы, совпадает с RU.
- В lab README нет явных ссылок `course/...`, поэтому обратных lab → chapter ссылок в текущем архиве для языковой проверки нет.
- Структура заголовков, таблиц и code blocks по переводам соответствует RU.
- В solutions после исключения переводимых комментариев/echo-текста последовательность исполняемых команд совпадает с RU; подтверждённых технических изменений команд не найдено.
- Помимо перечисленных ниже случаев, подтверждённых смысловых инверсий или потери обязательных условий не обнаружено.
