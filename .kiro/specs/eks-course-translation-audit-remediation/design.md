# Design Document

## Overview

Исправление заменяет содержимое двух неполных локализаций главы 7 полными переводами русского оригинала:

```text
07/ru.md ──> 07/jp.md
         └──> 07/tw.md
```

Переводы изолированы: японский агент изменяет только `jp.md`, а агент традиционного китайского - только `tw.md`. Это исключает конфликт записи. Технические блоки и относительные пути сохраняются, а переводится только человекочитаемый Markdown-текст, включая подписи Mermaid-узлов и таблицы там, где это не технические литералы.

## Translation rules

- Источник смысла: только `tasks/eks/course/07/ru.md`.
- Не переводятся: команды, YAML, shell-флаги, значения переменных окружения, CIDR, идентификаторы Mermaid-узлов, поля API и имена AWS/Kubernetes-ресурсов.
- Сохраняются 14 подразделов `7.1`–`7.14`, оба Mermaid-блока, таблицы, code fences, раздел практики и финальная навигация.
- Language_Switcher сохраняет установленный порядок языков и исключает язык текущего файла.
- JP использует `README_JP.md`, `../06/jp.md`, `../08/jp.md`, `README_JP.MD` лабы 103; TW использует эквивалентные TW-пути.

## Validation

После перевода выполняется один детерминированный набор проверок для обоих файлов:

1. Сравнить с `ru.md` количество `## `-заголовков, Mermaid-блоков, code fences, строк таблиц и директив Mermaid `style`.
2. Проверить ровно семь ссылок в первой строке и отсутствие self-link.
3. Проверить наличие правильной локальной ссылки на lab 103 и финальной навигации.
4. Проверить отсутствие кириллицы вне первой строки и отсутствие существенных английских предложений вне технических блоков.
5. Проверить отсутствие длинного тире `—` в целевых файлах.

Legacy-ссылки labs 02/03 намеренно исключены из проверки и изменений: они существуют в репозитории и требуют отдельного решения о политике локализации, а не исправления битой ссылки.
