# SRE Learning Platform のドキュメント

## コースと実践

コースは、ロシア語、英語、スペイン語、フランス語、ドイツ語、ジョージア語、繁体字中国語、日本語の8言語に対応しています。教材の先頭にあるリンクで言語を切り替えられます。

| コース | 学べる内容 | 実践 |
|---|---|---|
| **[CKA + CKAD](../tasks/cka/course/README_JP.md)** | 58章：Linux、ネットワーク、コンテナの基礎から、Kubernetes 管理、アプリケーション開発、トラブルシューティングまで | [ラボ](labs.MD#cka-labs), [CKA](../tasks/cka/mock) · [CKAD](../tasks/ckad/mock) |
| **[CKS](../tasks/cks/course/README_JP.md)** | 33章：脅威モデル、クラスターと OS の強化、アプリケーションセキュリティ、サプライチェーン、監査、インシデント調査 | [ラボ 101-115](labs.MD#cks-labs), [模擬試験](../tasks/cks/mock) |
| **[Amazon EKS](../tasks/eks/course/README_JP.md)** | 48章：AWS 上の Kubernetes のアーキテクチャと運用、コンピューティング、ネットワーク、アクセス、ストレージ、可観測性、アップグレード | [ラボ](labs.MD#eks-labs), 101-132 |
| **[Istio / ICA](../tasks/ica/course/README_JP.md)** | 32章：サービスメッシュ、トラフィック管理、mTLS、可観測性、ICA 対策、運用シナリオ | [35 ラボ](labs.MD#ica-labs-istio-certified-associate), [模擬試験](../tasks/ica/mock), [分野の概要](../tasks/ica/README_JP.MD) |
| **[KCSA](../tasks/kcsa/course/README_JP.md)** | 20章：クラウドネイティブセキュリティの基礎、Kubernetes コンポーネントのセキュリティ、脅威モデル、防御の仕組み | [問題と模擬試験](../tasks/kcsa/README_JP.md) |
