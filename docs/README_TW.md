# SRE Learning Platform 文件

## 課程與實作

課程提供八種語言版本：俄文、英文、西班牙文、法文、德文、喬治亞文、繁體中文及日文。請使用教材開頭的語言切換連結。

| 課程 | 學習內容 | 實作 |
|---|---|---|
| **[CKA + CKAD](../tasks/cka/course/README_TW.md)** | 58 章：從 Linux、網路與容器基礎，到 Kubernetes 管理、應用程式開發與疑難排解 | [實作練習](labs.MD#cka-labs), [CKA](../tasks/cka/mock) · [CKAD](../tasks/ckad/mock) |
| **[CKS](../tasks/cks/course/README_TW.md)** | 33 章：威脅模型、叢集與作業系統強化、應用程式安全、供應鏈、稽核及事件調查 | [實作練習 101-115](labs.MD#cks-labs), [模擬考試](../tasks/cks/mock) |
| **[Amazon EKS](../tasks/eks/course/README_TW.md)** | 48 章：AWS 上的 Kubernetes 架構與維運、運算資源、網路、存取、儲存、可觀測性與升級 | [實作練習](labs.MD#eks-labs), 101-132 |
| **[Istio / ICA](../tasks/ica/course/README_TW.md)** | 32 章：服務網格、流量管理、mTLS、可觀測性、ICA 備考與維運情境 | [35 實作練習](labs.MD#ica-labs-istio-certified-associate), [模擬考試](../tasks/ica/mock), [學習方向總覽](../tasks/ica/README_TW.MD) |
| **[KCSA](../tasks/kcsa/course/README_TW.md)** | 20 章：雲原生安全基礎、Kubernetes 元件安全、威脅模型與防護機制 | [題目與模擬考試](../tasks/kcsa/README_TW.md) |
