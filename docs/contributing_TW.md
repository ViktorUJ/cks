# 社群與專案貢獻

我們建立此平台，是希望讓社群都能取得知識與實務經驗。當大家分享教材、提出問題、驗證練習並協助修正錯誤時，專案就能持續成長。

您可以透過多種方式協助：

- 新增課程章節、實作練習、操作情境或題目解析。
- 修正技術錯誤、不精確之處、錯字或失效連結。
- 讓解說更清楚、補充範例，或改善題目的驗證方式。
- 新增或更新翻譯。
- 完成實作練習並分享回饋。

## 如何提出變更

1. 選擇您想新增或改善的教材。如果計畫新增大型章節，請先在 [Issues](https://github.com/ViktorUJ/cks/issues) 討論，或透過[聯絡方式](#contacts)與我們交流。
2. Fork 儲存庫，並在獨立分支進行修改，參考現有教材的結構。
3. 技術修正請描述問題與驗證方式。新增實作練習時，請依現有範例提供啟動說明、任務、結果驗證及解答。
4. 建立 [pull request](https://github.com/ViktorUJ/cks/pulls)，簡要說明變更內容。

如果暫時無法準備修正，也可以在 [Issues](https://github.com/ViktorUJ/cks/issues) 回報問題。實作練習的問題請附上練習編號、重現步驟及驗證結果。

我們隨時歡迎新成員。若想參與專案開發，請[聯絡我們](#contacts)。社群交流遵循[行為準則](CODE_OF_CONDUCT.md)。

## 如何支持專案

- 為[儲存庫](https://github.com/ViktorUJ/cks)加上一顆星，協助更多人發現平台。
- 向同事或學習小組分享平台。
- 在 [dev.to](https://dev.to/)、[Medium](https://medium.com/)、[HackerNoon](https://hackernoon.com) 或個人部落格分享您的使用經驗。
