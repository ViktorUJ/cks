# Documentación de SRE Learning Platform

## Cursos y práctica

Los cursos están disponibles en ocho idiomas: ruso, inglés, español, francés, alemán, georgiano, chino tradicional y japonés. El selector de idioma se encuentra al principio de los materiales.

| Curso | Qué aprenderás | Práctica |
|---|---|---|
| **[CKA + CKAD](../tasks/cka/course/README_ES.md)** | 58 capítulos: desde Linux, redes y contenedores hasta administración de Kubernetes, desarrollo de aplicaciones y resolución de problemas | [Laboratorios](labs.MD#cka-labs), [CKA](../tasks/cka/mock) · [CKAD](../tasks/ckad/mock) |
| **[CKS](../tasks/cks/course/README_ES.md)** | 33 capítulos: modelos de amenazas, protección del clúster y del sistema operativo, seguridad de aplicaciones, cadena de suministro, auditoría e investigación de incidentes | [Laboratorios 101-115](labs.MD#cks-labs), [Simulacros de examen](../tasks/cks/mock) |
| **[Amazon EKS](../tasks/eks/course/README_ES.md)** | 48 capítulos: arquitectura y operación de Kubernetes en AWS, cómputo, redes, acceso, almacenamiento, observabilidad y actualizaciones | [Laboratorios](labs.MD#eks-labs), 101-132 |
| **[Istio / ICA](../tasks/ica/course/README_ES.md)** | 32 capítulos: service mesh, gestión del tráfico, mTLS, observabilidad, preparación para ICA y escenarios de operación | [35 Laboratorios](labs.MD#ica-labs-istio-certified-associate), [Simulacros de examen](../tasks/ica/mock), [Resumen del área](../tasks/ica/README_ES.MD) |
| **[KCSA](../tasks/kcsa/course/README_ES.md)** | 20 capítulos: fundamentos de seguridad cloud native, seguridad de los componentes de Kubernetes, modelos de amenazas y controles de protección | [Preguntas y simulacros de examen](../tasks/kcsa/README_ES.md) |
