# コミュニティと貢献

このプラットフォームは、知識と実務経験をコミュニティで共有するために作られています。参加者が教材を共有し、質問し、課題を検証し、誤りの修正を手伝うことで、プロジェクトは成長します。

さまざまな形で協力できます。

- コースの章、ラボ、実践シナリオ、課題の解説を追加する。
- 技術的な誤り、不正確な表現、誤字、リンク切れを修正する。
- 説明を分かりやすくし、例を補い、課題の検証方法を改善する。
- 翻訳を追加、更新する。
- ラボに取り組み、フィードバックを共有する。

## 変更を提案する方法

1. 追加または改善したい教材を選びます。大きな章やセクションを新設する場合は、[Issues](https://github.com/ViktorUJ/cks/issues) で相談するか、[連絡先](#contacts)からご連絡ください。
2. リポジトリを fork し、既存の教材の構成に合わせて、別のブランチで変更を加えます。
3. 技術的な修正では、問題と修正結果の確認方法を説明してください。新しいラボには、既存の例を参考に、起動手順、課題、結果の検証方法、解答を含めてください。
4. 変更内容の簡単な説明を添えて [pull request](https://github.com/ViktorUJ/cks/pulls) を作成します。

修正を準備できない場合も、[Issues](https://github.com/ViktorUJ/cks/issues) で問題を報告できます。ラボの不具合では、ラボ番号、再現手順、検証結果を記載してください。

新しい参加者をいつでも歓迎しています。プロジェクトの開発に参加したい方は、[ご連絡ください](#contacts)。コミュニティでは[行動規範](CODE_OF_CONDUCT.md)を守って交流しています。

## プロジェクトを応援する方法

- [リポジトリ](https://github.com/ViktorUJ/cks)にスターを付けて、ほかの人にも見つけてもらいやすくする。
- 同僚や学習グループにプラットフォームを紹介する。
- [dev.to](https://dev.to/)、[Medium](https://medium.com/)、[HackerNoon](https://hackernoon.com)、個人ブログなどで利用経験を紹介する。
