# საზოგადოება და პროექტში მონაწილეობა

ამ პლატფორმას ვქმნით, რათა ცოდნა და პრაქტიკული გამოცდილება საზოგადოებისთვის ხელმისაწვდომი იყოს. პროექტი ვითარდება, როცა მონაწილეები მასალებს აზიარებენ, კითხვებს სვამენ, დავალებებს ამოწმებენ და შეცდომების გასწორებაში გვეხმარებიან.

დახმარება სხვადასხვა გზით შეგიძლიათ:

- დაამატოთ კურსის თავი, ლაბორატორიული სამუშაო, პრაქტიკული სცენარი ან ამოცანის განხილვა.
- გაასწოროთ ტექნიკური შეცდომა, უზუსტობა, ბეჭდვითი შეცდომა ან არამუშა ბმული.
- უფრო გასაგები გახადოთ ახსნა, შეავსოთ მაგალითი ან გააუმჯობესოთ დავალების შემოწმება.
- დაამატოთ ან განაახლოთ თარგმანი.
- გაიაროთ ლაბორატორიული სამუშაო და გაგვიზიაროთ შეფასება.

## როგორ შემოგვთავაზოთ ცვლილება

1. აირჩიეთ მასალა, რომლის დამატება ან გაუმჯობესება გსურთ. თუ დიდი ახალი განყოფილების შექმნას გეგმავთ, განიხილეთ ის [Issues-ში](https://github.com/ViktorUJ/cks/issues) ან დაგვიკავშირდით [კონტაქტების](#contacts) მეშვეობით.
2. შექმენით რეპოზიტორიის fork და ცვლილებები ცალკე branch-ში შეიტანეთ, არსებული მასალების სტრუქტურის გათვალისწინებით.
3. ტექნიკური შესწორებისთვის აღწერეთ პრობლემა და შედეგის შემოწმების გზა. ახალი ლაბორატორიული სამუშაოსთვის დაურთეთ გაშვების ინსტრუქციები, დავალებები, შედეგის შემოწმება და გადაწყვეტა არსებული სამუშაოების მსგავსად.
4. გახსენით [pull request](https://github.com/ViktorUJ/cks/pulls) ცვლილებების მოკლე აღწერით.

თუ ჯერ შესწორების მომზადება არ შეგიძლიათ, პრობლემის შესახებ [Issues-ში](https://github.com/ViktorUJ/cks/issues) შეგვატყობინეთ. ლაბორატორიული სამუშაოს შეცდომისთვის მიუთითეთ ნომერი, პრობლემის გამეორების ნაბიჯები და შემოწმების შედეგი.

ახალ მონაწილეებს ყოველთვის მივესალმებით. თუ პროექტის განვითარებაში ჩართვა გსურთ, [მოგვწერეთ](#contacts). ურთიერთობისას ვიცავთ [ქცევის კოდექსს](CODE_OF_CONDUCT.md).

## როგორ დაუჭიროთ მხარი პროექტს

- მიანიჭეთ [რეპოზიტორიას](https://github.com/ViktorUJ/cks) ვარსკვლავი, რათა სხვებს მისი პოვნა გაუადვილდეთ.
- გაუზიარეთ პლატფორმა კოლეგებს ან თქვენს სასწავლო ჯგუფს.
- დაწერეთ თქვენი გამოცდილების შესახებ [dev.to-ზე](https://dev.to/), [Medium-ზე](https://medium.com/), [HackerNoon-ზე](https://hackernoon.com) ან პირად ბლოგში.
