# SRE Learning Platform documentation

## Courses and practice

Courses are available in eight languages: Russian, English, Spanish, French, German, Georgian, Traditional Chinese, and Japanese. Use the language switcher at the top of the learning materials.

| Course | What you will learn | Practice |
|---|---|---|
| **[CKA + CKAD](../tasks/cka/course/README.md)** | 58 chapters: from Linux, networking, and containers to Kubernetes administration, application development, and troubleshooting | [Labs](labs.MD#cka-labs), [CKA](../tasks/cka/mock) · [CKAD](../tasks/ckad/mock) |
| **[CKS](../tasks/cks/course/README.md)** | 33 chapters: threat modeling, cluster and OS hardening, application security, supply chains, auditing, and incident investigation | [Labs 101-115](labs.MD#cks-labs), [Mock exams](../tasks/cks/mock) |
| **[Amazon EKS](../tasks/eks/course/README.md)** | 48 chapters: Kubernetes architecture and operations in AWS, compute, networking, access, storage, observability, and upgrades | [Labs](labs.MD#eks-labs), 101-132 |
| **[Istio / ICA](../tasks/ica/course/README.md)** | 32 chapters: service mesh, traffic management, mTLS, observability, ICA preparation, and operational scenarios | [35 Labs](labs.MD#ica-labs-istio-certified-associate), [Mock exams](../tasks/ica/mock), [Track overview](../tasks/ica/README.MD) |
| **[KCSA](../tasks/kcsa/course/README.md)** | 20 chapters: cloud native security fundamentals, Kubernetes component security, threat models, and protective controls | [Questions and mock exams](../tasks/kcsa/README.md) |
