# Глоссарий курса KCSA

Английские термины оставлены в исходной форме, потому что они нужны для чтения условий и вариантов KCSA. Описание объясняет смысл по-русски, но не заменяет тренировку терминов в английских MCQ.

| Термин | Описание | Типичная путаница | Главы |
|---|---|---|---|
| `4C model` | Модель слоёв Cloud, Cluster, Container и Code для анализа защиты cloud native. | Не сводится только к инфраструктуре облака. | [03](03/ru.md) |
| `ABAC` | Авторизация по атрибутам запроса и субъекта. | Не является RBAC с ролями. | [10](10/ru.md) |
| `Access control` | Ограничение доступа к ресурсу по правилам и идентичности. | Шире одной только authentication. | [10](10/ru.md) |
| `Admission control` | Этап API после authentication и authorization, который допускает или изменяет объект. | Не подтверждает identity и не выдаёт права. | [11](11/ru.md), [17](17/ru.md) |
| `Admission policy` | Декларативное правило проверки объектов при admission. | Не равна audit policy. | [17](17/ru.md) |
| `Admission webhook` | Внешний webhook, участвующий в mutating или validating admission. | Не является сетевым webhook приложения. | [17](17/ru.md) |
| `Alert` | Сигнал, требующий внимания или реакции по правилу. | Не заменяет первичные логи и метрики. | [18](18/ru.md) |
| `Allowlist` | Явный список разрешённых источников, действий или объектов. | Не равен отсутствию deny-правил. | [09](09/ru.md), [17](17/ru.md) |
| `Anomaly detection` | Выявление отклонения от ожидаемого поведения. | Аномалия сама по себе не доказывает атаку. | [18](18/ru.md) |
| `API server` | Компонент, принимающий Kubernetes API-запросы и координирующий доступ к состоянию. | Не хранит состояние вместо etcd. | [07](07/ru.md) |
| `Artifact` | Результат разработки или сборки, например image, пакет или SBOM. | Не обязательно является container image. | [06](06/ru.md), [17](17/ru.md) |
| `Attack surface` | Совокупность точек, через которые систему можно атаковать. | Не является одной найденной уязвимостью. | [02](02/ru.md), [16](16/ru.md) |
| `Attack vector` | Конкретный путь или способ реализации атаки. | Уже, чем attack surface. | [15](15/ru.md), [16](16/ru.md) |
| `Audit backend` | Настроенное место хранения или передачи audit-событий API Server. | API Server создаёт события, backend их сохраняет или получает. | [14](14/ru.md) |
| `Audit logging` | Регистрация событий запросов к Kubernetes API. | Не заменяет runtime detection процессов. | [14](14/ru.md) |
| `Audit policy` | Конфигурация, определяющая, какие API-события и с какой детализацией записывать. | Не является admission policy. | [14](14/ru.md) |
| `Authentication` | Установление того, кто делает запрос. | Не отвечает на вопрос, разрешено ли действие. | [10](10/ru.md) |
| `Authorization` | Проверка, может ли уже известный субъект выполнить действие. | Не устанавливает identity. | [10](10/ru.md) |
| `Authorization mode` | Настроенный механизм принятия решения об API-правах. | Не равен способу authentication. | [10](10/ru.md) |
| `Availability` | Доступность данных или сервиса уполномоченному пользователю. | Не равна конфиденциальности или целостности. | [02](02/ru.md), [16](16/ru.md) |
| `Backup` | Копия данных для восстановления после потери или повреждения. | Backup также должен быть защищён как исходные данные. | [07](07/ru.md), [12](12/ru.md) |
| `Base64` | Обратимое кодирование байтов для текстового представления. | Не является encryption. | [12](12/ru.md) |
| `Baseline profile` | Уровень PSS, блокирующий известные опасные настройки при сохранении совместимости. | Не равен наиболее строгому restricted profile. | [11](11/ru.md) |
| `Bearer token` | Токен, предъявление которого даёт права его владельца. | Не равен паролю, который можно безопасно поместить в код. | [10](10/ru.md) |
| `Bound ServiceAccount token` | Короткоживущий токен, привязанный к ServiceAccount и Pod. | Не равен старому долгоживущему Secret-токену. | [10](10/ru.md) |
| `Build provenance` | Provenance с данными о сборке артефакта. | Не равна подписи или SBOM. | [17](17/ru.md), [19](19/ru.md) |
| `CA` | Центр сертификации, которому доверяют выпуск или проверку сертификатов. | Не является закрытым ключом. | [18](18/ru.md) |
| `Certificate` | Документ с публичным ключом и идентичностью, подписанный доверенным CA. | Не содержит закрытый ключ. | [18](18/ru.md) |
| `Certificate authority` | Полное название CA как доверенной стороны PKI. | Не равен любому TLS-сертификату. | [18](18/ru.md) |
| `CIA triad` | Три цели безопасности: confidentiality, integrity и availability. | Не является моделью угроз или control. | [02](02/ru.md), [15](15/ru.md) |
| `Cilium` | CNI и набор сетевых средств, способных применять NetworkPolicy. | Не является самим API-ресурсом NetworkPolicy. | [13](13/ru.md) |
| `CIS Kubernetes Benchmark` | Набор рекомендаций по безопасной конфигурации Kubernetes. | Это framework рекомендаций, не готовый control. | [05](05/ru.md), [19](19/ru.md) |
| `Cloud` | Внешний слой модели 4C: инфраструктура, IAM и сервисы провайдера. | Не тождественен Kubernetes cluster. | [03](03/ru.md), [04](04/ru.md) |
| `Cloud IAM` | Управление идентичностями и правами к облачным ресурсам. | Не заменяет Kubernetes RBAC. | [04](04/ru.md) |
| `Code` | Слой 4C с исходным кодом, зависимостями и практиками разработки. | Не равен уже собранному image. | [03](03/ru.md), [06](06/ru.md) |
| `Compliance` | Соответствие применимым требованиям с подтверждаемыми evidence. | Не гарантирует отсутствие всех рисков. | [19](19/ru.md) |
| `Confidentiality` | Защита данных от раскрытия неуполномоченным сторонам. | Не равна integrity или availability. | [02](02/ru.md), [12](12/ru.md) |
| `Container` | Изолированный процесс с образом и ограничениями runtime. | Не равен Pod, который может содержать несколько контейнеров. | [03](03/ru.md), [09](09/ru.md) |
| `Container image` | Неизменяемый шаблон файлов и метаданных для запуска контейнера. | Не равен работающему container. | [06](06/ru.md), [17](17/ru.md) |
| `Container runtime` | Программный слой, запускающий контейнеры на узле через CRI. | Не равен kubelet. | [08](08/ru.md) |
| `Control` | Конкретная мера, снижающая вероятность риска или его последствия. | Не равен framework, который структурирует меры. | [05](05/ru.md), [19](19/ru.md) |
| `Control plane` | Логическая совокупность компонентов, управляющих состоянием Kubernetes. | Не равен worker node. | [07](07/ru.md) |
| `Controller Manager` | Компонент, запускающий контроллеры для приведения состояния к желаемому. | Не выбирает узел для Pod. | [07](07/ru.md) |
| `CRI` | Интерфейс Kubernetes между kubelet и container runtime. | Не является CNI или CSI. | [08](08/ru.md) |
| `CVE` | Идентификатор публично известной уязвимости. | CVE не равен доказанной эксплуатации. | [06](06/ru.md), [16](16/ru.md) |
| `Data flow` | Путь передачи данных между участниками системы. | Не равен trust boundary, но пересекает её. | [15](15/ru.md) |
| `Default deny` | Стартовая политика, запрещающая неявно неразрешённый трафик. | Не равна запрету всего API-доступа. | [13](13/ru.md) |
| `Defense in depth` | Сочетание независимых слоёв защиты. | Не означает дублировать один и тот же control. | [02](02/ru.md), [05](05/ru.md) |
| `Denial of Service` | Нарушение доступности через истощение или перегрузку ресурсов. | Не равен любой медленной работе системы. | [16](16/ru.md) |
| `Deployment` | Kubernetes-ресурс для управления ReplicaSet и обновлениями Pod. | Не является отдельной границей безопасности. | [02](02/ru.md), [09](09/ru.md) |
| `Detection` | Обнаружение уже наблюдаемого события или отклонения. | Не предотвращает объект до создания. | [14](14/ru.md), [18](18/ru.md) |
| `Digest` | Криптографический идентификатор конкретного содержимого артефакта. | Не доказывает автора, безопасность или происхождение. | [06](06/ru.md), [17](17/ru.md) |
| `DNS` | Служба разрешения имён для сервисов и внешних адресов. | Не является механизмом network segmentation. | [09](09/ru.md) |
| `Egress` | Исходящий сетевой трафик от выбранного Pod. | Не равен ingress-трафику к Pod. | [13](13/ru.md), [18](18/ru.md) |
| `Encryption` | Криптографическая защита данных с применением ключа. | Не равна обратимому encoding. | [04](04/ru.md), [12](12/ru.md) |

| `Encryption in transit` | Шифрование данных во время передачи по сети. | Не заменяет authorization или segmentation. | [04](04/ru.md), [18](18/ru.md) |

| `Etcd` | Хранилище состояния Kubernetes control plane. | Не является API Server. | [07](07/ru.md), [12](12/ru.md) |
| `Evidence` | Проверяемое свидетельство работы control или процесса. | Не равна самому требованию compliance. | [14](14/ru.md), [19](19/ru.md) |
| `Exploit` | Код или техника, использующая уязвимость. | Не каждая vulnerability имеет известный exploit. | [16](16/ru.md) |
| `External Secrets Operator` | Оператор, синхронизирующий секреты из внешнего хранилища. | После синхронизации риски Kubernetes Secret остаются. | [12](12/ru.md) |
| `Falco` | Средство runtime detection поведения контейнеров и узлов. | Не заменяет audit logging API-запросов. | [16](16/ru.md), [18](18/ru.md) |

| `FQDN` | Полное доменное имя сетевой цели. | Не является IP-адресом или identity. | [09](09/ru.md), [18](18/ru.md) |
| `Framework` | Структура для оценки рисков, требований или полноты controls. | Не является техническим control сам по себе. | [05](05/ru.md), [19](19/ru.md) |
| `gVisor` | Sandbox runtime, добавляющий изоляцию между workload и ядром узла. | Не заменяет PSS, RBAC и NetworkPolicy. | [05](05/ru.md) |

| `Scheduler` | Компонент, выбирающий узел для нового Pod. | Не запускает контейнеры на узле. | [07](07/ru.md) |
| `Secret` | Kubernetes API-объект для чувствительных небольших данных. | Base64 в `data` не является encryption. | [12](12/ru.md) |
| `SecurityContext` | Настройки привилегий и ограничений процесса или Pod. | Не заменяет PSS, RBAC или NetworkPolicy. | [09](09/ru.md), [11](11/ru.md) |
| `Segmentation` | Разделение системы на зоны с ограниченными взаимодействиями. | Это один из способов isolation, а не её полный синоним. | [13](13/ru.md), [15](15/ru.md) |
| `Service mesh` | Инфраструктурный слой для сервисной connectivity, identity и часто mTLS. | Не заменяет NetworkPolicy. | [18](18/ru.md) |
| `ServiceAccount` | Kubernetes-идентичность для процессов в Pod. | Не даёт прав без RBAC. | [10](10/ru.md), [12](12/ru.md) |
| `Shared responsibility` | Распределение обязанностей по защите между провайдером и клиентом. | Не означает, что провайдер защищает workload клиента. | [04](04/ru.md) |
| `SIEM` | Система централизации и корреляции security-событий. | Не является источником audit-событий API Server. | [14](14/ru.md), [18](18/ru.md) |
| `Signature` | Криптографическое доказательство, связывающее данные с подписывающим ключом. | Не равна digest, SBOM или provenance. | [06](06/ru.md), [17](17/ru.md) |
| `SLSA` | Framework требований к цепочке поставки с независимыми tracks Build и Source. | Не является универсальным названием reproducible build. | [17](17/ru.md), [19](19/ru.md) |
| `SOC 2` | Проверка controls сервисной организации по Trust Services Criteria. | Не является Kubernetes security standard. | [19](19/ru.md) |
| `Software supply chain` | Путь кода, зависимостей, сборки и доставки до runtime. | Не ограничивается container registry. | [06](06/ru.md), [17](17/ru.md) |
| `SPIFFE` | Стандарт идентичностей workload для распределённых систем. | Не является TLS-сертификатом сам по себе. | [18](18/ru.md) |
| `STRIDE` | Framework моделирования угроз по шести категориям. | Не является журналом фактических атак. | [15](15/ru.md), [19](19/ru.md) |
| `Subject` | Пользователь, группа или ServiceAccount, от имени которого действует запрос. | Не равен Role или permission. | [10](10/ru.md) |
| `Supply chain` | Цепочка создания и поставки программного артефакта. | Не равна одному этапу сборки. | [17](17/ru.md), [19](19/ru.md) |
| `Syscall` | Системный вызов процесса к ядру ОС. | Не является Kubernetes API-вызовом. | [16](16/ru.md), [18](18/ru.md) |
| `Tag` | Человекочитаемая ссылка на версию image. | Может быть mutable и не равна digest. | [06](06/ru.md) |
| `Threat` | Возможная причина или сценарий нежелательного события. | Не равен vulnerability или оценённому risk. | [15](15/ru.md), [16](16/ru.md) |
| `Threat model` | Описание активов, границ, потоков и угроз системы. | Не является списком CVE. | [15](15/ru.md), [19](19/ru.md) |
| `TLS` | Протокол шифрования и аутентификации соединения. | Не заменяет NetworkPolicy или authorization. | [07](07/ru.md), [18](18/ru.md) |
| `Token` | Учётные данные, предъявляемые для authentication. | Не равен автоматически ограниченному RBAC-доступу. | [10](10/ru.md) |
| `Trace` | Связанный маршрут запроса через распределённые сервисы. | Не равен отдельной log-записи. | [18](18/ru.md) |
| `Trust boundary` | Место, где меняются доверие, права или контроль данных. | Не обязательно совпадает с namespace. | [15](15/ru.md) |
| `Trusted registry` | Registry, которому политика разрешает поставлять images. | Не доказывает отсутствие CVE в image. | [06](06/ru.md), [17](17/ru.md) |
| `Vulnerability` | Слабость, которую может использовать угроза или exploit. | Не равна threat или risk. | [06](06/ru.md), [16](16/ru.md) |
| `Vulnerability scanner` | Средство поиска известных уязвимостей по данным о компонентах. | Не предотвращает поведение runtime. | [06](06/ru.md), [17](17/ru.md) |
| `Webhook` | HTTP-обработчик, вызываемый Kubernetes или другим компонентом. | Не каждый webhook относится к admission. | [10](10/ru.md), [17](17/ru.md) |
| `Workload` | Запускаемое приложение и управляющий его Kubernetes-ресурс. | Не равен одному container image. | [03](03/ru.md), [09](09/ru.md) |
| `Zero trust` | Подход без неявного доверия к сети, identity или расположению. | Не означает запретить все взаимодействия. | [02](02/ru.md), [18](18/ru.md) |

## Лексические ловушки

- [Authentication](10/ru.md) устанавливает identity, [authorization](10/ru.md) проверяет право, а [admission control](11/ru.md) оценивает допустимость объекта после первых двух стадий.
- [Audit logging](14/ru.md) отвечает за API-события, а [runtime detection](18/ru.md) - за поведение процесса после запуска.
- [Encryption](12/ru.md) требует ключа для защиты данных, [Base64](12/ru.md) - только обратимое encoding.
- [Digest](06/ru.md) фиксирует содержимое, [signature](17/ru.md) связывает данные с ключом, [SBOM](17/ru.md) перечисляет компоненты, а [provenance](17/ru.md) описывает происхождение.
- [Isolation](13/ru.md) охватывает несколько границ, [segmentation](13/ru.md) разделяет их на зоны и пути.
- [Control](05/ru.md) уменьшает риск, [framework](19/ru.md) помогает выбирать и оценивать controls.
- [Vulnerability](16/ru.md) - слабость, [threat](15/ru.md) - возможный сценарий, [risk](19/ru.md) - оценка вероятности и последствий.
- [Logging](18/ru.md) сохраняет события, [monitoring](18/ru.md) отслеживает известные показатели, [observability](18/ru.md) позволяет объяснять состояние по разным сигналам.
- [CIA triad](02/ru.md) объединяет [confidentiality](12/ru.md), [integrity](19/ru.md) и [availability](16/ru.md).
