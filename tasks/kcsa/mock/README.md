# KCSA Mock Exams

This directory contains KCSA practice exams in multiple-choice format: a question, four answer options, an answer key, and a short explanation linked to a course chapter. These are not labs: the official KCSA exam has no hands-on tasks.

- [Mock Exam 01](01/README.md) - an English training simulation with 60 questions distributed 8/13/13/10/10/6 across the domains.
- [Mock Exam 02](02/README.md) - an independent English training simulation with 60 questions distributed 8/13/13/10/10/6 across the domains.

Take each mock in a closed-book, 90-minute session: do not use documentation, search, notes, tools, or external websites. As of 2026-09-01, the LF Multiple Choice FAQ lists a passing score of 75% or above; confirm KCSA registration requirements with the Linux Foundation. Use the [course contents and preparation route](../course/README_RU.md) to study.
