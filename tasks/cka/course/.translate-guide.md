## Что переводим

- прозу, заголовки, подписи узлов и рёбер mermaid (только текст внутри `"..."`),
  текстовые ячейки таблиц, врезки/блокквоты, комментарии `# ...` внутри блоков кода,
  текст ссылок (`[Сеть: IP, порты...]` -> перевод).

## Что НЕ переводим

- код, команды, флаги, пути, IP/CIDR/порты, YAML-ключи и значения-код;
- имена ресурсов и термины Kubernetes/Linux: Pod, Service, Ingress, Deployment,
  StatefulSet, ConfigMap, Secret, Namespace (как ресурс), kube-apiserver, etcd,
  kubelet, kube-proxy, containerd, CRI, runc, OCI, cgroup, namespaces (Linux),
  ClusterIP, NodePort, LoadBalancer, Pod CIDR, Service CIDR, NAT, RBAC, CNI, CSI и т.п.;
- в mermaid НЕ менять id узлов и строки `style ...` / `classDef` - только текст подписи в кавычках.

## Формат

- Тире - обычный дефис `-`, не длинное тире.
- Структура, нумерация разделов, `<br>`, таблицы, блоки кода - 1:1 с `ru.md`.
- Ничего не сокращать и не пропускать. Файл пишется целиком.
- Записывать через `fs_write` (первая часть) + `fs_append` (остальные части).

## Обязательная самопроверка в конце

```bash
cd /home/viktor/work/cks/tasks/cka/course
d=<CHAPTER>; f=<TARGET_BASENAME_WITHOUT_EXT>
for x in ru "$f"; do printf '%s: ##=%s ###=%s mermaid=%s style=%s code=%s lines=%s\n' \
  "$x" "$(grep -c '^## ' $d/$x.md)" "$(grep -c '^### ' $d/$x.md)" \
  "$(grep -c '```mermaid' $d/$x.md)" "$(grep -c 'style ' $d/$x.md)" \
  "$(grep -c '```' $d/$x.md)" "$(wc -l < $d/$x.md)"; done
grep -n '[а-яА-Я]' $d/$f.md
```

Требования:
- `##`, `###`, `mermaid`, `style`, число ``` ``` `` совпадают с `ru.md`;
- кириллица допустима ТОЛЬКО в строке 1 (метка «Русская версия») и внутри кода,
  если она есть в `ru.md`; непереведённой русской прозы быть не должно;
- если что-то не сходится - найти пропуск и дописать/исправить.

Ничего не коммитить. Файлы `ru.md` и лабы (`tasks/cka/labs/`) не изменять.
