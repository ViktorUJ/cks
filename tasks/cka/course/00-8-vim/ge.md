# თავი 0.8. vim 15 წუთში: გადარჩი და მოირგე YAML-ისთვის

> **ვისთვისაა ეს თავი.** მოკლე პრაქტიკული მინიმუმი რედაქტორ `vim`-ზე. CKA/CKAD
> გამოცდებზე და კლასტერის კვანძებზე ეს არის ნაგულისხმევი რედაქტორი, და მასში მუდმივად
> იმუშავებთ (მანიფესტები, კონფიგები, `/etc/...`). მიზანი არ არის „vim-ის სწავლა“, არამედ
> ის, რომ მასზე დროს არ კარგავდეთ: შედი, დაარედაქტირე, შეინახე, გამოდი და სწორად მოირგე
> სცემები YAML-ისთვის. თუ vim-ში უკვე თავდაჯერებულად მუშაობთ - გამოტოვეთ თავი.

## 0.8.1. ორი რეჟიმი - მთავარი, რაც უნდა გაიგოთ

vim-ში დამწყების მთელი აღრევა **რეჟიმებისგან** მოდის. კლავიშები სხვადასხვა რამეს
აკეთებენ იმის მიხედვით, რომელ რეჟიმში ხართ.

```mermaid
flowchart LR
    normal["NORMAL<br>ბრძანებები: გადაადგილება,<br>წაშლა, შენახვა"] -->|"დააჭირე i"| insert["INSERT<br>ტექსტის ჩვეულებრივი აკრეფა"]
    insert -->|"დააჭირე Esc"| normal
    style normal fill:#326ce5,color:#fff
    style insert fill:#0f9d58,color:#fff
```

- **NORMAL** (ნაგულისხმევი შესვლისას) - კლავიშები ბრძანებებია, არა ტექსტი.
- **INSERT** - ტექსტის ჩვეულებრივი შეყვანა; შედიან კლავიშით `i`, გამოდიან - `Esc`.

გადარჩენის წესი: **თუ რაღაც არასწორად წავიდა - დააჭირე `Esc`** (დაბრუნდები Normal-ში),
და მხოლოდ მერე ბრძანება.

## 0.8.2. მინიმალური ბრძანებები გადასარჩენად

ეს ნაკრები საკმარისია გამოცდაზე სამუშაოს 95%-ისთვის:

| მოქმედება | კლავიშები (Normal რეჟიმიდან) |
|-----------|------------------------------|
| რედაქტირებაში შესვლა | `i` |
| რედაქტირებიდან გამოსვლა | `Esc` |
| შენახვა | `:w` + Enter |
| შენახვა და გამოსვლა | `:wq` ან `ZZ` |
| გამოსვლა შენახვის გარეშე | `:q!` |
| გაუქმება / დაბრუნება | `u` / `Ctrl+r` |
| სტრიქონის წაშლა | `dd` |
| სტრიქონის კოპირება / ჩასმა | `yy` / `p` |
| ფაილის დასაწყისში / ბოლოში | `gg` / `G` |
| ძებნა | `/ტექსტი` + Enter (შემდეგი - `n`) |
| სტრიქონების ნომრები | `:set number` |

ფაილის გახსნა: `vim file.yaml`. სულ ესაა. მეტი გამოცდაზე ჩვეულებრივ არც არის საჭირო.

## 0.8.3. YAML-ისთვის მორგება - აუცილებელია

vim-ის მთავარი უბედურება Kubernetes-თან მუშაობისას: **ტაბები სივრცეების ნაცვლად** და
„მცოცავი“ სცემები. YAML კრძალავს ტაბებს (თავი 0.6), ხოლო vim ნაგულისხმევად შესაძლოა
ისინი ჩასვას. ამიტომ პირველი, რასაც გამოცდაზე აკეთებენ, - ქმნიან `~/.vimrc`-ს:

```vim
set expandtab       " Tab ჩასვამს სივრცეებს, არა ტაბს
set tabstop=2       " ტაბის სიგანე - 2 სივრცე
set shiftwidth=2    " ავტოსცემის სცემა - 2 სივრცე
set number          " სტრიქონების ნომრები
set autoindent      " ახალ სტრიქონზე სცემის შენარჩუნება
syntax on           " სინტაქსის გამოკვეთა
```

ამ კონფიგით კლავიში Tab იძლევა ორ სივრცეს, და მანიფესტები სცემებზე არ იტეხება.
`~/.vimrc`-ის მორგება ღირს **პირველ რიგში** გაკეთდეს გამოცდაზე (ეს შედის თავი 1-ის
საწყის მოქმედებებში).

## 0.8.4. ხაფანგი ჩასმისას (paste)

როცა თქვენ (მაუსით) სვამთ მზა YAML-ს vim-ში Insert რეჟიმში ჩართული `autoindent`-ით,
სცემები **კასკადურად იზრდება** - თითოეული სტრიქონი უფრო და უფრო მარჯვნივ იწევს. ასე
მკურნალობენ:

```vim
:set paste      " ჩასმამდე - თიშავს ავტოსცემას
" ... სვამთ ტექსტს ...
:set nopaste    " ჩასმის შემდეგ - დააბრუნეთ ჩვეულებრივი რეჟიმი
```

თუ ჩასმის შემდეგ დაინახეთ სცემების „კიბე“ - სწორედ ესაა. `:set paste`, გააუქმეთ (`u`),
ხელახლა ჩასვით.

## 0.8.5. მინი-ლექსიკონი

- **Normal რეჟიმი** - vim-ის ბრძანებების რეჟიმი (ნაგულისხმევი); კლავიშები ბრძანებებია.
- **Insert რეჟიმი** - ტექსტის აკრეფის რეჟიმი; შესვლა `i`, გამოსვლა `Esc`.
- **`:wq` / `:q!`** - შენახვა და გამოსვლა / გამოსვლა შენახვის გარეშე.
- **`~/.vimrc`** - vim-ის პარამეტრების ფაილი (სცემები, სტრიქონების ნომრები).
- **`expandtab`** - ტაბის სივრცეებით ჩანაცვლება (კრიტიკულია YAML-ისთვის).
- **`:set paste`** - ჩასმის რეჟიმი ავტოსცემის გარეშე („კიბის“ საწინააღმდეგოდ).

## 0.8.6. თავის შეჯამება

- vim-ს ორი რეჟიმი აქვს: Normal (ბრძანებები) და Insert (ტექსტი); გადასვლა - `i` და
  `Esc`. დაიბენით - დააჭირეთ `Esc`.
- გადარჩენის მინიმუმი: `i`, `Esc`, `:wq`, `:q!`, `u`, `dd`, `/ძებნა`, `:set number`.
- YAML-ისთვის აუცილებლად მოირგეთ `~/.vimrc` (`expandtab`, `tabstop=2`, `shiftwidth=2`) -
  სხვაგვარად ტაბები მანიფესტებს დაამტვრევს.
- მზა ტექსტის ჩასმისას გამოიყენეთ `:set paste`, რომ სცემები არ „ცოცავდეს“.

## 0.8.7. როგორ გამოგადგებათ: გამოცდაზე და რეალურ სამუშაოში

**გამოცდაზე.** რედაქტორი თქვენი მთავარი ინსტრუმენტია 2 საათის განმავლობაში.
vim-თან ფათურში დაკარგული წუთები - ეს გადაუჭრელი ამოცანებია. მორგებული `~/.vimrc` და
ათიოდე ბრძანება დროს ზოგავს ყოველ ამოცანაზე მანიფესტთან.

**რეალურ სამუშაოში.** vim ნებისმიერ Linux-კვანძზეა ინსტალაციის გარეშე - როცა კონფიგს
ასწორებ სერვერზე SSH-ით, ხშირად არჩევანი არ არის. vim-ის საბაზისო ფლობა ინჟინრის
სავალდებულო უნარია.

## 0.8.8. თვითშემოწმების კითხვები

1. რით განსხვავდება Normal რეჟიმი Insert-ისგან და როგორ გადავრთოთ მათ შორის?
2. როგორ შევინახოთ ფაილი და გამოვიდეთ? როგორ გამოვიდეთ შენახვის გარეშე?
3. რატომაა YAML-ისთვის აუცილებელი `expandtab`-ისა და 2 სივრცის სცემის მორგება?
4. რა ვქნათ, თუ ტექსტის ჩასმის შემდეგ სცემები „კიბესავით ჩამოცოცდა“?

## პრაქტიკა

თავს ცალკე ლაბი არ აქვს: vim-ს გამოიყენებთ ყველა შემდგომ ლაბსა და მოკ-გამოცდაში,
მანიფესტების რედაქტირებისას. მოირგეთ `~/.vimrc` ერთხელ - და დაივიწყეთ სცემების
პრობლემა. შემდეგ იწყება ძირითადი კურსი - თავი 1.
