# 第 0.8 章。15 分鐘學會 vim:先活下來,再調成適合 YAML

> **這一章適合誰。** 這是關於 `vim` 編輯器的簡短實用最小集。在 CKA/CKAD 考試
> 以及叢集節點上,它就是預設編輯器,而你會不斷用它來編輯(manifest、設定檔、
> `/etc/...`)。目標不是「學會 vim」,而是不要把時間浪費在它上面:進去、
> 編輯、儲存、離開,並正確設定 YAML 的縮排。如果你已經能自信地使用 vim -
> 就跳過這一章。

## 0.8.1. 兩種模式 - 最重要的一件事

新手在 vim 中的所有混亂都來自 **模式**。同一個按鍵在不同的模式下
會做不同的事。

```mermaid
flowchart LR
    normal["NORMAL<br>命令:移動、<br>刪除、儲存"] -->|"按 i"| insert["INSERT<br>普通的文字輸入"]
    insert -->|"按 Esc"| normal
    style normal fill:#326ce5,color:#fff
    style insert fill:#0f9d58,color:#fff
```

- **NORMAL**(進入時的預設)- 按鍵是命令,不是文字。
- **INSERT** - 普通的文字輸入;用 `i` 進入,用 `Esc` 離開。

生存法則:**只要有什麼不對就按 `Esc`**(這樣會回到 Normal 模式),
然後再輸入命令。

## 0.8.2. 活下來所需的最少命令

這一組就足以應付考試上 95% 的工作:

| 動作 | 按鍵(從 Normal 模式) |
|----------|----------------------------|
| 進入編輯 | `i` |
| 離開編輯 | `Esc` |
| 儲存 | `:w` + Enter |
| 儲存並離開 | `:wq` 或 `ZZ` |
| 不儲存離開 | `:q!` |
| 復原 / 重做 | `u` / `Ctrl+r` |
| 刪除一行 | `dd` |
| 複製 / 貼上一行 | `yy` / `p` |
| 到檔案開頭 / 結尾 | `gg` / `G` |
| 搜尋 | `/文字` + Enter(下一個 - `n`) |
| 行號 | `:set number` |

開啟檔案:`vim file.yaml`。就這樣。考試上通常不需要更多。

## 0.8.3. 針對 YAML 的設定 - 必做

在 Kubernetes 工作中使用 vim 的最大麻煩是:**用 tab 而不是空格**,以及縮排
「跑掉」。YAML 禁止 tab(第 0.6 章),而 vim 預設可能會插入它們。所以考試上
第一件事就是建立 `~/.vimrc`:

```vim
set expandtab       " Tab 插入空格,而不是 tab
set tabstop=2       " tab 寬度 - 2 個空格
set shiftwidth=2    " 自動縮排的寬度 - 2 個空格
set number          " 行號
set autoindent      " 換新行時保留縮排
syntax on           " 語法高亮
```

有了這個設定,Tab 鍵會給出兩個空格,manifest 也不會在縮排上壞掉。
設定 `~/.vimrc` 值得在考試上 **第一時間** 完成(這屬於第 1 章的
起始動作)。

## 0.8.4. 貼上(paste)的陷阱

當你在啟用 `autoindent` 的 Insert 模式下(用滑鼠)把現成的 YAML 貼進
vim 時,縮排會 **層層累加** - 每一行都越來越往右移。這樣治它:

```vim
:set paste      " 貼上之前 - 關閉自動縮排
" ... 你貼上文字 ...
:set nopaste    " 貼上之後 - 回到普通模式
```

如果貼上後看到縮排變成「階梯」- 就是這個原因。`:set paste`、復原(`u`)、
再貼一次。

## 0.8.5. 迷你詞彙表

- **Normal 模式** - vim 的命令模式(預設);按鍵就是命令。
- **Insert 模式** - 文字輸入模式;用 `i` 進入,用 `Esc` 離開。
- **`:wq` / `:q!`** - 儲存並離開 / 不儲存離開。
- **`~/.vimrc`** - vim 的設定檔(縮排、行號)。
- **`expandtab`** - 用空格取代 tab(對 YAML 至關重要)。
- **`:set paste`** - 不做自動縮排的貼上模式(對付「階梯」)。

## 0.8.6. 本章總結

- vim 有兩種模式:Normal(命令)與 Insert(文字);切換用 `i` 與 `Esc`。慌了
  就按 `Esc`。
- 生存最小集:`i`、`Esc`、`:wq`、`:q!`、`u`、`dd`、`/搜尋`、`:set number`。
- 針對 YAML 一定要設定 `~/.vimrc`(`expandtab`、`tabstop=2`、`shiftwidth=2`)-
  否則 tab 會把 manifest 弄壞。
- 貼上現成文字時使用 `:set paste`,讓縮排不會「跑掉」。

## 0.8.7. 這些知識用在哪裡:考試與實際工作

**在考試上。** 編輯器是你連續 2 小時的主要工具。花在跟 vim 搏鬥上的分鐘,
就是沒解出來的題目。設定好的 `~/.vimrc` 加上十來個命令,能在每一道 manifest
題目上省下時間。

**在實際工作中。** 任何 Linux 節點上都有 vim,不需安裝 - 當你透過 SSH 在
伺服器上改設定檔時,常常沒有別的選擇。基本的 vim 操作能力是工程師的
必備技能。
