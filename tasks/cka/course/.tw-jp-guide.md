# Инструкция: перевод глав курса на TW (традиционный китайский) и JP (японский)

Базовый каталог: `/home/viktor/work/cks/tasks/cka/course`
Источник всегда `<CHAPTER>/ru.md`. Цель: `<CHAPTER>/tw.md` или `<CHAPTER>/jp.md`.

Дополнительно прочитай `.translate-guide.md` в том же каталоге - общие правила
(что переводим, что нет, mermaid, формат) действуют полностью.

## Эталоны

- Структура и ретаргет ссылок: `<CHAPTER>/README.md` (английская версия той же главы).
- Стиль и терминология TW: `00-1-net/tw.md`.
- Стиль и терминология JP: `00-1-net/jp.md` (если ещё нет - `../labs/101/README_JP.MD`).

## Переключатель языков

ПЕРВАЯ строка целевого файла, дословно, ничего не менять. Затем ПУСТАЯ строка,
затем `# ...` как в `ru.md`.

- для `tw.md`:

```
[Русская версия](ru.md) · [Eng version](README.md) · [Versión en español](es.md) · [Version française](fr.md) · [Deutsche Version](de.md) · [ქართული ვერსია](ge.md) · [日本語版](jp.md)
```

- для `jp.md`:

```
[Русская версия](ru.md) · [Eng version](README.md) · [Versión en español](es.md) · [Version française](fr.md) · [Deutsche Version](de.md) · [ქართული ვერსია](ge.md) · [繁體中文版](tw.md)
```

Пути на каталоги (`../../mock`, `../../../ckad/mock`, `../../labs`) НЕ менять.
Номер главы/лабы НЕ менять - меняется только имя файла.

## Служебные слова

| Русский | TW | JP |
|---------|----|----|
| Оглавление | 目錄 | 目次 |
| Глава N | 第 N 章 | 第 N 章 |
| Часть 0 | 第 0 部分 | パート 0 |
| Практика | 實踐 | practice |
| Лаба | 實驗 | ラボ |

Для JP «Практика» как заголовок раздела - `演習`, «Лаба NNN» - `ラボ NNN`.

## Пунктуация

- TW: полноширинная - `。`, `、`, `,`, `(`, `)`.
- JP: `。`, `、`, скобки полноширинные `（）` в прозе допустимы, но
  для единообразия с остальными языками используй обычные `()` вокруг
  латиницы/кода.
- Тире - обычный дефис `-`, не длинное тире.

## Что НЕ переводим

Код, команды, флаги, пути, IP/CIDR/порты, YAML-ключи и значения-код, base64,
`check_result`, `TASK=NNN make ...`, имена ресурсов и термины Kubernetes/Linux
(Pod, Service, Ingress, Deployment, StatefulSet, ConfigMap, Secret, Namespace,
kube-apiserver, etcd, kubelet, kube-proxy, containerd, CRI, runc, OCI, cgroup,
ClusterIP, NodePort, LoadBalancer, RBAC, CNI, CSI и т.п.).

В mermaid переводим ТОЛЬКО текст внутри кавычек. Id узлов и строки
`style ...` / `classDef ...` - побайтово 1:1 с `ru.md`.

## Формат

Структура, нумерация разделов, `<br>`, таблицы, блоки кода - 1:1 с `ru.md`.
Ничего не сокращать и не пропускать, файл пишется целиком.
Писать через `fs_write` (первая часть) + `fs_append` (остальные части).

## Обязательная самопроверка

```bash
cd /home/viktor/work/cks/tasks/cka/course
d=<CHAPTER>; t=<tw|jp>
for f in ru $t; do printf '%s ##=%s ###=%s mm=%s st=%s code=%s tbl=%s ln=%s cyr=%s\n' \
  $f "$(grep -c '^## ' $d/$f.md)" "$(grep -c '^### ' $d/$f.md)" \
  "$(grep -c '```mermaid' $d/$f.md)" "$(grep -cE '^ *style ' $d/$f.md)" \
  "$(grep -c '```' $d/$f.md)" "$(grep -c '^|' $d/$f.md)" \
  "$(wc -l < $d/$f.md)" "$(grep -c '[а-яА-Я]' $d/$f.md)"; done
```

Требуется: `##`, `###`, `mm`, `st`, `code`, `tbl` совпадают с `ru`; `cyr=1`.
Расхождение `ln` допустимо. Если не сходится - найди пропуск, исправь, повтори.

Ничего не коммитить. `ru.md` не изменять. Файлы в `tasks/cka/labs/` не изменять.

## Ответ

Покажи ТОЛЬКО вывод самопроверки плюс резюме в 2-3 строки.
НЕ выводи содержимое переведённого файла.
КРИТИЧНО: в тексте ответа НЕ упоминай путей и имён файлов (ни `tw.md`, ни
`jp.md`, ни каталогов) - только номер главы, язык и счётчики. Упоминание пути
запускает лишнее чтение файла и съедает контекст.
