# Lab 109 — reference solution (observability: probes, logs, debugging, deprecations)

## Task 1. Pod `app1233` with a livenessProbe (exec)

```bash
kubectl create namespace web-ns
```

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: app1233
  namespace: web-ns
spec:
  containers:
  - name: app1233
    image: viktoruj/ping_pong:alpine
    livenessProbe:
      exec:
        command: ["ls", "/etc"]
      initialDelaySeconds: 10
      periodSeconds: 60
```

## Task 2. Three probes for a slow-starting application (`web-probes`)

The `ping_pong` application with `DELAY_START=30` starts listening on `:8080` only after 30
seconds — this simulates a long start. The startupProbe provides the startup budget, while
liveness/readiness kick in only after it succeeds.

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: web-probes
  namespace: web-ns
spec:
  containers:
  - name: web-probes
    image: viktoruj/ping_pong:latest
    ports:
    - containerPort: 8080
    env:
    - name: DELAY_START
      value: "30"
    startupProbe:
      httpGet:
        path: /
        port: 8080
      periodSeconds: 5
      failureThreshold: 12      # a budget of 5 × 12 = 60 s for startup
    readinessProbe:
      httpGet:
        path: /
        port: 8080
      periodSeconds: 10
    livenessProbe:
      httpGet:
        path: /
        port: 8080
      periodSeconds: 10
```

```bash
kubectl apply -f web-probes.yaml
# 0/1 at first (the startupProbe is running), Ready after roughly 30 s
kubectl -n web-ns get pod web-probes -w
```

The "startupProbe versus `initialDelaySeconds`" case is covered in the README.

## Task 5. Fix the outdated manifest and deploy it

The file `/var/work/109/app-old.yaml` uses the removed `apps/v1beta1` and does not contain the
required `selector`. We fix it to the current version:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: app-21
spec:
  replicas: 1
  selector:
    matchLabels:
      app: app-21
  template:
    metadata:
      labels:
        app: app-21
    spec:
      containers:
      - name: app-21
        image: viktoruj/ping_pong:alpine
```

```bash
kubectl apply -f /var/work/109/app-old.yaml
kubectl get deploy app-21
```

You can look up the current API version with `kubectl explain deployment` and
`kubectl api-versions`.
