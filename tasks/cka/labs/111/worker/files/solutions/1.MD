# Lab 111 — reference solution (kubeadm cluster upgrade)

The cluster starts on `1.33.1`. The task is to upgrade the control plane and the worker to
`1.33.2`. Order: control plane first, then the worker; we upgrade nodes one at a time,
draining them with cordon/drain.

We take the node names from `kubectl get nodes` — **the same names are used both for `ssh`
and for `drain`/`uncordon`** (in this environment they resolve: `ssh <node-name>` works):

```bash
kubectl get nodes
# note the names, for example:
CP=ip-10-10-1-151        # control plane (the control-plane role in the output)
WORKER=ip-10-10-1-81     # worker (role <none>)
```

## Step 1. Control plane

```bash
# log in to the control plane node
ssh $CP

# upgrade kubeadm to 1.33.2
sudo apt-mark unhold kubeadm
sudo apt-get update && sudo apt-get install -y kubeadm=1.33.2-1.1
sudo apt-mark hold kubeadm
kubeadm version -o short          # v1.33.2

sudo kubeadm upgrade plan
sudo kubeadm upgrade apply v1.33.2 -y
exit
```

```bash
# from the work machine, drain the control plane
kubectl drain $CP --ignore-daemonsets --delete-emptydir-data

# upgrade kubelet and kubectl on the node itself
ssh $CP '
  sudo apt-mark unhold kubelet kubectl
  sudo apt-get install -y kubelet=1.33.2-1.1 kubectl=1.33.2-1.1
  sudo apt-mark hold kubelet kubectl
  sudo systemctl daemon-reload && sudo systemctl restart kubelet
'

kubectl uncordon $CP
```

## Step 2. Worker node

```bash
# from the work machine, drain the worker
kubectl drain $WORKER --ignore-daemonsets --delete-emptydir-data

# on the worker node, upgrade kubeadm and the node configuration
ssh $WORKER '
  sudo apt-mark unhold kubeadm
  sudo apt-get update && sudo apt-get install -y kubeadm=1.33.2-1.1
  sudo apt-mark hold kubeadm
  sudo kubeadm upgrade node
  sudo apt-mark unhold kubelet kubectl
  sudo apt-get install -y kubelet=1.33.2-1.1 kubectl=1.33.2-1.1
  sudo apt-mark hold kubelet kubectl
  sudo systemctl daemon-reload && sudo systemctl restart kubelet
'

# from the work machine, put the worker back in service
kubectl uncordon $WORKER
```

## Verification

```bash
kubectl get nodes    # all nodes v1.33.2, Ready
```

> Note: if the `1.33.2-1.1` packages are not available, check what is available with
> `apt-cache madison kubeadm` and use a current 1.33.x patch (then adjust `TARGET` in the
> validation).
