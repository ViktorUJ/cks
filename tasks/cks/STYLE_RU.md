# Стиль русскоязычных материалов CKS

Этот файл применяется к русскому тексту в `course/` и `labs/`. Команды, YAML, имена API,
пути, точные сообщения программ и цитируемый вывод не подвергаются языковой «чистке».

## Термины

| English | Предпочтительная форма |
|---|---|
| workload | рабочая нагрузка |
| worker node | рабочий узел |
| control-plane node | узел control plane / узел управляющей плоскости |
| scheduler | планировщик (`kube-scheduler`) |
| builder | сборщик / узел сборки |
| review | проверка / ревью |

Имена Kubernetes API и ресурсов не переводятся произвольно и оформляются как code:
`Pod`, `Deployment`, `NetworkPolicy`, `ServiceAccount`, `SecurityContext`, `Namespace`.
В обычном тексте допустимы русские падежные конструкции вокруг literal имени: «для
`Pod`», «в объекте `Deployment`», но не окончания через апостроф (`pod'ы`, `workload'ов`).

Используйте «рабочий узел» вместо `worker-нода`, «узел control plane» вместо
`control-plane нода`. Не создавайте гибриды `builder-е`, `review-ятся` и подобные формы.

## Проверка

Перед релизом проверьте текст вне code blocks и вручную разберите каждое совпадение:

```bash
rg -n --glob '*.md' --glob '*.MD' \
  "[A-Za-zА-Яа-яЁё][\x27’][а-яё]+|worker[- ]нода|control-plane нода|builder-[еуа]|review-(ятся|ится)" \
  course labs
```

Совпадение в команде или дословном программном выводе может быть допустимо; совпадение в
русском повествовательном тексте должно быть исправлено.
