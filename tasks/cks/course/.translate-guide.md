## Что переводим

- Прозу, заголовки, подписи узлов и рёбер mermaid только внутри кавычек, текст ячеек таблиц, врезки, комментарии `# ...` в блоках кода и текст ссылок.
- Текст навигации, названия частей, лабораторных работ, критериев и пояснений.

## Что не переводим

- Команды, флаги, пути, IP/CIDR/порты, YAML-ключи и значения-код.
- Имена Kubernetes/Linux-ресурсов и терминов: Pod, Service, Ingress, Deployment, ConfigMap, Secret, Namespace, kube-apiserver, etcd, kubelet, containerd, CRI, RBAC, CNI, CSI, NetworkPolicy, RuntimeClass, CiliumNetworkPolicy и т.п.
- В mermaid не менять идентификаторы узлов, строки `style ...` и `classDef`; переводится только подпись в кавычках.

## Формат

- Тире - обычный дефис `-`, не длинное тире.
- Структура, нумерация разделов, таблицы, `<br>`, блоки кода и ссылки сохраняются 1:1 с русским исходником.
- Ничего не сокращать и не пропускать. Русские исходники после фазы 4 не изменять.

## Обязательная самопроверка

Для каждой главы после перевода:

```bash
cd /home/viktor/work/cks/tasks/cks/course
d=<CHAPTER>; f=<TARGET_BASENAME_WITHOUT_EXT>
for x in ru "$f"; do printf '%s: ##=%s ###=%s mermaid=%s style=%s code=%s lines=%s\n' \
  "$x" "$(grep -c '^## ' "$d/$x.md")" "$(grep -c '^### ' "$d/$x.md")" \
  "$(grep -c '```mermaid' "$d/$x.md")" "$(grep -c 'style ' "$d/$x.md")" \
  "$(grep -c '```' "$d/$x.md")" "$(wc -l < "$d/$x.md")"; done
grep -n '[а-яА-Я]' "$d/$f.md"
```

Требования: число `## `, `### `, `mermaid`, `style ` и блоков кода совпадает с исходником; число строк может отличаться из-за языка. Кириллица допустима только в первой строке-переключателе и внутри кода, если она есть в `ru.md`. Для навигации, лаб и решений примените тот же подсчёт к соответствующей паре файлов и проверьте все ретаргетированные ссылки.

Ничего не коммитить. Не изменять `tasks/cka`, `tasks/ckad` и русские исходники при переводе.
