# Мок-экзамены CKS

Четыре мок-экзамена под таймером (~120 минут каждый), смешивающие задания из всех доменов сразу - по формату близко к реальному экзамену CKS (15-20 performance-based задач, 2 часа). Каждый мок разворачивает несколько кластеров/контекстов и проверяется автоматически через `check_result` на work pc.

| Мок | Заданий | Особенности |
|---|---:|---|
| [Мок 01](01/README.MD) | 18 | Общая репетиция по всем доменам |
| [Мок 02](02/README.MD) | 20 | Общая репетиция по всем доменам |
| [Мок 03](03/README.MD) | 22 | Помимо обычного `check_result` (все 22 задания) есть `check_result_timed` - отдельная проверка только по первым 20 заданиям, реалистично соответствующим официальному диапазону 15-20 задач |
| [Мок 04](04/README.MD) | 16 | Общая репетиция по всем доменам |

Рекомендуемый порядок: пройдите [лабораторные работы](../labs) и главы [курса](../course/README_RU.md) по конкретным темам, а моки используйте в конце подготовки как репетицию под давлением времени - Level 3 в общей схеме практики курса (см. [README курса](../course/README_RU.md#практика)).

Каждый мок - самостоятельная практика; они не заменяют глубину лабораторных работ 101-113, где механизм и failure modes разбираются подробно с evidence-артефактами.
