# Amazon EKS: პრაქტიკული თვითმასწავლებელი production-ექსპლუატაციისთვის

Amazon EKS-ის პრაქტიკული კურსი, რომელიც მიბმულია ლაბორატორიულ სამუშაოებზე
`tasks/eks/labs`-ში. კურსი განკუთვნილია ინჟინრებისთვის, რომლებმაც **უკვე გაიარეს CKA** (ან
Kubernetes-ს ადმინისტრატორის დონეზე თავდაჯერებულად ფლობენ) და AWS-ში მართულ
კლასტერზე გადადიან.

EKS-ის ცალკე სერტიფიკაცია არ არსებობს, ამიტომ კურსი აგებულია არა გამოცდისთვის,
არამედ რეალური ექსპლუატაციისთვის: იმისთვის, რაზეც ინჟინრი აგებს პასუხს, როდესაც control plane-ს
AWS ემსახურება, ხოლო ნოდები, ქსელი, წვდომები, ხარჯები და განახლებები კვლავ თქვენზეა.

> **რა უნდა იცოდეთ წინასწარ.** Pod-ები, Deployment, Service, Ingress, RBAC,
> PV/PVC, probes, kubectl, სამუშაო დატვირთვების გამართვა - ეს CKA კურსის საფუძველია და აქ
> აღარ მეორდება. თუ ეს თემები ჯერ არ გაქვთ ათვისებული, დაიწყეთ
> [CKA + CKAD კურსით](../../cka/course/README_GE.md).

> **ვერსიები.** კურსი ორიენტირებულია EKS-ის აქტუალურ ვერსიებზე (Kubernetes `1.33` -
> `1.36`). EKS-ს ვერსიების საკუთარი სასიცოცხლო ციკლი აქვს: 14 თვე standard support და დამატებით
> 12 თვე extended support (მინორულ ვერსიაზე სულ 26 თვე), ამიტომ განახლებების თავი
> მიბმულია არა კონკრეტულ ნომერზე, არამედ პროცესზე. კურსის ლაბები იქმნება იმ ვერსიაზე,
> რომელიც თითოეული ლაბის `env.hcl`-შია მითითებული.

## როგორ არის აგებული კურსი

თითოეული თემა ნომრიანი საქაღალდეა. შიგნით განთავსებულია ლოკალიზებული ფაილები. ძირითადი ენაა
რუსული (`ru.md`), მისგან გაკეთებულია თარგმანები (როგორც CKA-სა და Istio-ს კურსებში).
ენების გადამრთველი ყოველი ფაილის პირველ სტრიქონშია.

კურსისთვის საჭიროა **საკუთარი AWS ანგარიში**: თემების უმეტესობის შემოწმება მხოლოდ ცოცხალ
კლასტერზეა შესაძლებელი, ხოლო ზოგიერთი მათგანის (spot-შეფერხებები, NAT და ტრაფიკი, განახლებები, ხარჯები)
ლოკალურ kind-ში გამეორება შეუძლებელია. ლაბები იქმნება Terragrunt-ის მეშვეობით და
ერთი ბრძანებით იშლება, რათა ზედმეტი ხარჯი არ წარმოიქმნას.

თავებისა და ლაბების გარდა, კურსს აქვს სამუშაო ცნობარები, რომლებსაც თანმიმდევრულად კი არა, საჭიროებისამებრ კითხულობენ:

- [კურსის გლოსარიუმი](GLOSSARY_GE.md) - ყველა ტერმინი თავების მიხედვით ბმულებით
- [დიაგნოსტიკური ცნობარი](RUNBOOK_GE.md) - სიმპტომი, მიზეზი, შემოწმება: შეჯამებული ნაწილი 8
- [არქიტექტურული გადაწყვეტილებები (ADR)](ADR_GE.md) - კურსის არჩევის წერტილებისთვის გადაწყვეტილებების შაბლონები
- [EKS-ის სიმწიფის მატრიცა](SCORECARD_GE.md) - კლასტერის მზადყოფნის კითხვარი რვა დომენის მიხედვით
- [ხარჯების მოდელი](COST_MODEL_GE.md) - ხარჯების მუხლებისა და ფორმულების ჩამონათვალი, ტარიფებს თავად უთითებთ
