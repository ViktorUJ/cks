## Как продолжать (проверенный рабочий процесс)

1. Один сабагент (general-task-execution) = одна глава, последовательно.
2. В промпт сабагента класть contextFiles: .chapter-spec.md, README_RU.md, 1-2 соседние
   готовые главы для стиля, и .content-notes.md если у главы есть обязательные требования.
3. В промпте: точное название из README_RU.md; первая строка "# Глава N. <название>";
   первый раздел ОТ ПРОБЛЕМЫ; служебные разделы пронумерованы; "## Практика" без номера;
   навигация в подвале на N-1 и N+1; разграничение с соседними главами (что отдать куда).
4. Требовать проверку фактов по docs.aws.amazon.com, не выдумывать команды/числа, без цен в
   долларах (только структура стоимости).
5. После сабагента проверять bash-ом (сабагент сам файл в ответ не выводит):
   grep -c "—" (должно быть 0); grep -c "🧪" (0, лаб пока нет); python-проверка mermaid
   (<=8 узлов, style только на существующие узлы); wc -l (цель 300-360, насыщенные до ~400 ок).
